# Football Manager 4

نسخة تطوير مستقلة للعبة إدارة كرة القدم، موجهة للهواتف ومتوافقة مع العربية وRTL.

## مبدأ التطوير
- هذا المستودع مستقل تماماً عن Football Manager 3.
- نقطة البداية هي نقل النسخة المرجعية العاملة للحفاظ على أنظمة النادي والواجهة.
- محرك المباراة سيُعاد تصميمه واختباره على مراحل؛ النسخة المنقولة ليست بعدُ محرك FM4 النهائي.
- لا تُقبل تغييرات المباراة دون اختبارات للتمركز، انتقال الكرة بين الخطوط، الاستحواذ، التسديدات، التبديلات، والوقت التلقائي.

## ترتيب المراحل
1. تثبيت خط أساس قابل للتشغيل.
2. فصل منطق المباراة عن الواجهة.
3. بناء محرك أحداث ومواقع مترابط بدلاً من توليد أحداث منفصلة عن حركة الكرة.
4. اختبارات آلية للمباراة والحفظ.
5. تطوير قاعدة البيانات ثم أنظمة النادي.
6. التحقق من PWA وAndroid قبل اعتماد كل إصدار.

## التشغيل
افتح index.html عبر خادم محلي أو استضف المستودع على GitHub Pages. يدعم التطبيق التثبيت كـ PWA عند الاستضافة عبر HTTPS.

## تنبيه
هذه نسخة تطويرية. لا تستخدمها لمسيرة طويلة قبل اختبار الحفظ والترحيل والتحديثات.
