# Football Manager 4

نسخة تطوير مستقلة للعبة إدارة كرة القدم، موجهة للهواتف ومتوافقة مع العربية وRTL.

## مبدأ التطوير
- هذا المستودع مستقل تماماً عن Football Manager 3.
- نقطة البداية هي نقل النسخة المرجعية العاملة للحفاظ على أنظمة النادي والواجهة.
- محرك المباراة سيُعاد تصميمه واختباره على مراحل؛ النسخة المنقولة ليست بعدُ محرك FM4 النهائي.
- لا تُقبل تغييرات المباراة دون اختبارات للتمركز، انتقال الكرة بين الخطوط، الاستحواذ، التسديدات، التبديلات، والوقت التلقائي.

## ترتيب المراحل
1. تثبيت خط أساس قابل للتشغيل.
2. فصل منطق المباراة عن الواجهة.
3. بناء محرك أحداث ومواقع مترابط بدلاً من توليد أحداث منفصلة عن حركة الكرة.
4. اختبارات آلية للمباراة والحفظ.
5. تطوير قاعدة البيانات ثم أنظمة النادي.
6. التحقق من PWA وAndroid قبل اعتماد كل إصدار.

## التشغيل
افتح index.html عبر خادم محلي أو استضف المستودع على GitHub Pages. يدعم التطبيق التثبيت كـ PWA عند الاستضافة عبر HTTPS.

## تنبيه
هذه نسخة تطويرية. لا تستخدمها لمسيرة طويلة قبل اختبار الحفظ والترحيل والتحديثات.

## معاينة محرك المباراة الجديد
- افتح `match-preview.html` عبر خادم محلي أو GitHub Pages بعد نشر الفرع.
- المعاينة تستخدم تشكيلتين تجريبيتين، وتعرض تحرك اللاعبين والكرة، الوقت التلقائي، الاستحواذ، التسديدات، والتمريرات والأحداث.
- يمكن إيقاف المباراة، تحريك دقيقة واحدة، تغيير السرعة، وتبديل عقلية الفريق الأزرق.
- المعاينة معزولة عن `index.html` ولا تقرأ أو تعدّل ملف الحفظ؛ لم يتم استبدال محرك المباراة القديم.

## تجربة المحرك داخل المباراة الحقيقية (Shadow Mode)
- عند بدء مباراة من الواجهة الرئيسية، تُنشأ محاكاة موازية للمحرك الجديد تلقائياً.
- تظهر لوحة **المحاكاة الموازية — وضع آمن** أسفل لوحة النتيجة، وتعرض دقيقة المحرك، نتيجته، الاستحواذ، التسديدات، التمريرات المكتملة، عدد اللاعبين النشطين وآخر الأحداث.
- تستمر المباراة الأصلية في إدارة النتيجة والحفظ والميزانية والتقدم؛ المحرك الموازي للقراءة والمقارنة فقط ولا يكتب إلى حالة المسيرة.
- تُزامن لوحة المحاكاة تبديلات فريق المستخدم وحالات الطرد، وتدعم وقتاً يصل إلى 120 دقيقة.
- إذا تعذّر تشغيل المحرك الموازي، تظهر رسالة تشخيصية وتستمر المباراة الأصلية دون تعطيل.
- عند الاختبار على الهاتف، راقب اللوحة في الدقائق 1 و15 و45 وبعد أي تبديل وعند الدقيقة 90/الوقت الإضافي. قارن اختلاف النتيجة والتسديدات والاستحواذ؛ اختلاف النتائج متوقع لأن المحركين مستقلان.
- لا تعتمد النسخة لمسيرة طويلة أو APK إنتاجي قبل اختبارها يدوياً على الهاتف والتحقق من استقرارها.
